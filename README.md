# The UX Review Blog

A responsive blog landing page with a bold, neo-brutalist style, built with HTML and CSS only.

## Sections

- Navbar with a CSS-only mobile menu
- Hero
- Latest articles with trending and categories sidebar
- Authors
- Community and testimonials
- Footer with newsletter form

## Project Structure

```
├── index.html
├── CSS/
│   ├── style.css           # base (desktop) styles
│   └── media-query.css     # responsive styles
└── Images/
    └── Icons/
```

## Getting Started

Open `index.html` in any modern browser.

## Responsive Breakpoints

| Screen width | Main changes |
|---|---|
| Above 1100px | Full navbar, multi-column layout |
| 1100px and below | Menu button, one column |
| 767px and below | Smaller headings, stacked article cards |
| 480px and below | Compact spacing, full-width hero buttons |

## Note

This is a front-end practice project. The newsletter form has no backend.
